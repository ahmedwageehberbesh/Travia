# Travia — معاك كام؟

تطبيق ويب تجريبي لتخطيط رحلات داخل مصر حسب **ميزانيتك**.  
يعمل بالكامل من المتصفح **بدون باك‌اند** — بيانات تجريبية جاهزة + اختياري Gemini AI.

**Live demo:** [https://ahmedwageehberbesh.github.io/Travia/](https://ahmedwageehberbesh.github.io/Travia/)

---

## المميزات

- اختيار **كل المحافظات المصرية (27 محافظة)** مع صورة لمعالم كل محافظة (أهرامات، شرم، الغردقة، الأقصر…)
- تحديد **الميزانية**، عدد الأشخاص، ومدة الرحلة
- اختيار **نوع الرحلة** (بحر، استجمام، مغامرات، آثار، شهر عسل)
- نتائج فورية: 3 خطط (اقتصادية / متوازنة / مريحة) ضمن أو قريبة من ميزانيتك
- واجهة **عربي / English**
- تسجيل دخول تجريبي (localStorage — بدون سيرفر)
- **Gemini AI** اختياري لتوليد نصوص أغنى للخطط
- جاهز لـ **GitHub Pages**

## التشغيل محلياً

> **مهم:** لا تفتح `index.html` مباشرة (`file://`) — ES Modules مش هتشتغل.  
> لازم سيرفر محلي.

```powershell
cd client
npm install   # اختياري — المشروع ما فيه dependencies
npm start
```

افتح: **http://localhost:3000**

---

## Gemini API (اختياري)

1. انسخ ملف البيئة:

```powershell
copy .env.example .env
```

2. ضع مفتاحك في `.env`:

```env
GEMINI_API_KEY=AIza...
```

3. حوّل الإعدادات لملف يقرأه المتصفح:

```powershell
npm run env
```

أو شغّل `npm start` — بيعمل sync تلقائي قبل التشغيل.

> المفتاح في `.env` **مش بيترفع على Git**.  
> تقدر كمان تحفظ المفتاح من زر **✨ Gemini** داخل التطبيق (localStorage).

## GitHub Pages

1. ارفع الملفات على فرع `main` في repo `ahmedwageehberbesh/Travia`
2. من **Settings → Pages** اختر Source: **Deploy from branch** → `main` → `/ (root)`
3. الرابط: `https://ahmedwageehberbesh.github.io/Travia/`

تأكد إن الملفات في **جذر الريبو** (مش داخل مجلد فرعي).

## كيف يشتغل البحث؟

1. المستخدم يختار محافظة ونوع الرحلة والميزانية
2. `demo-search.js` يبني 3 خطط بأسعار مختلفة حسب المحافظة
3. النتائج تظهر في الصفحة — كل كارت فيه صورة المحافظة وتفاصيل الرحلة
4. لو Gemini متوصل، النصوص ممكن تت enrich (اختياري)
